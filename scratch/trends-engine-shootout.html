Trends · engine shootout

Three real engines, same data, same page.

Every chart below is live and interactive — hover, click a legend row, watch it animate. The exact same three datasets (revenue, visits per doctor, no-show rate) run through three different rendering approaches, so this is a fair comparison of feel, not just a description. Colors and shell are deliberately pushed further than Qlinic's current look — theme-matching was explicitly not the goal here.

Hand-rolled SVG Chart.js ApexCharts
Option 1 · zero dependencies

Hand-rolled SVG

Plain SVG + vanilla JS — no library, ~4KB of code total. Every pixel and every interaction is something we wrote and fully control, including exact color/dark-mode matching. The tradeoff: every new chart type is more code we own.

Option 2 · CDN library

Chart.js

The most widely used web charting library — canvas-based, huge plugin ecosystem, built-in animation and tooltips. ~205KB from a CDN (same pattern Qlinic already uses for Supabase). Every visual detail here (gradient fill, center label, rounded bars) is a documented Chart.js option, not a hack.

Option 3 · CDN library

ApexCharts

The "modern SaaS dashboard" look out of the box — built-in gradients, smooth curves, a zoom/pan toolbar, and a genuinely nice default dark theme. ~535KB from a CDN, the heaviest of the three options here. Try the toolbar icons on the area chart (top-right on hover).
