How receipt numbers work
Each receipt number is issued once, never reused and never deleted. Only visits that reached the queue (arrived, not just booked) are billed, so a booked appointment or a no-show never gets a number. A patient is billed automatically when they arrive, unless the doctor had no fee set at that moment. Anyone listed above was seen but has no invoice on file, so set the doctor's fee and then use Open billing.
